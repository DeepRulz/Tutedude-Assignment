# Laundry Wallah Web Server

A simple Node.js web server project built using core Node modules.

## Features

- Multiple routes
- External HTML pages
- Asynchronous file handling using fs module
- Modular route handling
- Custom 404 page
- Reusable navbar component

## Technologies Used

- Node.js
- HTTP Module
- FS Module
- Path Module
